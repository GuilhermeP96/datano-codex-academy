# DatanO Codex Academy

Portal público em português. HTML/CSS/JavaScript nativos, sem backend ou chave de API.
Conteúdo em `src/content.js`; comportamento em `src/app.js`. Preserve caminhos relativos para GitHub Pages.
Consulte fontes oficiais antes de atualizar comandos. Registre a data de revisão em `docs/SOURCES.md`.
Validação: `npm run check`, `npm test`, `npm run build`. Confira desktop, celular, teclado e acessibilidade.
Nunca apresente o simulador como execução real do Codex. Progresso é local; não publique dados do aluno.
Logo e paleta DatanO vêm do site canônico gp96combr. A marca não pertence à OpenAI.
