# Vitrine pública Datano

HTML/CSS/JS estáticos com caminhos relativos. Identidade Datano derivada do site canônico.

Este repositório é público. Inclua MCPs e projetos comprovadamente públicos, a apresentação genérica IRobot-Not com cenários fictícios e as duas jornadas introdutórias gratuitas autorizadas pelo proprietário (Codex/Claude, três aulas cada). Não copie aulas pagas, fontes privadas, dados corporativos, configurações, arquitetura interna ou credenciais.

A Academy privada fica em https://academy.datano.com.br; este site oferece somente introduções públicas autorais e aponta para as trilhas completas pagas. O histórico inicial público permanece; não reescreva commits nem use force-push.

npm run check, npm test e npm run build validam a vitrine. O build usa uma lista explícita de arquivos públicos. GitHub Pages publica o build na branch gh-pages, pasta /; o main não é publicado automaticamente.

Alterações de visibilidade em outros repositórios não fazem parte desta implementação.
