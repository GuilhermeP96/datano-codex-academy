# Vitrine pública DatanO

HTML/CSS/JS estáticos com caminhos relativos. Identidade DatanO derivada do site canônico.

Este repositório é público. Inclua somente MCPs e projetos comprovadamente públicos e a apresentação genérica IRobot-Not com cenários fictícios. Não copie aulas pagas, fontes privadas, dados corporativos, configurações, arquitetura interna ou credenciais.

A Academy privada fica em https://academy.datano.com.br; este site apenas aponta para ela. O histórico inicial público permanece; não reescreva commits nem use force-push.

npm run check, npm test e npm run build validam a vitrine. O build usa uma lista explícita de arquivos públicos. GitHub Pages publica o build na branch gh-pages, pasta /; o main não é publicado automaticamente.

Alterações de visibilidade em outros repositórios não fazem parte desta implementação.
