# Primeira entrega com IA — DatanO
Um projeto gratuito completo: corrigir um pipeline de vendas fictícias com IA.
Requisitos: Python 3.10+, editor, Git opcional e sua ferramenta de IA autenticada.
1. Execute `python verificar.py`: inicialmente falha porque pipeline.py é o exercício.
2. Leia CONTRATO.md e use a jornada na Academy ou na vitrine pública.
3. Implemente pipeline.py com auxílio da IA, revise e rode o verificador.
4. Registre evidências e crie ENTREGA.md com comandos, resultado e limitações.
5. Execute em uma pasta nova antes de considerar entregue.
Não exige pip, APIs, instalação de servidores ou serviços pagos nesta página.
O uso da ferramenta de IA segue as condições do fornecedor escolhido.
