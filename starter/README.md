# Prática opcional com código — Datano

Nunca programou? Faça primeiro a atividade completa em https://academy.datano.com.br/comecar, escolhendo **Sem programação**. Ela usa somente um chat de IA e seu navegador. Não precisa deste kit nem de instalações.

Este kit é a segunda opção, para quem quer praticar a construção de um programa com IA. Você vai corrigir uma tarefa que organiza vendas fictícias e produz um relatório.

## Antes de começar
Você precisa de Python 3.10+ (o programa que executa os arquivos .py), um editor para abrir os arquivos e uma ferramenta de IA. Git é opcional. O kit não exige pacotes adicionais ou conexão a APIs.

Uma pasta reúne os arquivos da atividade. Um terminal é a janela em que você escreve um comando para o computador executar. Se esses termos ainda são novos, volte à atividade sem programação e conclua seu primeiro relatório antes desta prática.

## Um passo por vez
1. Extraia o ZIP em uma pasta de estudo. Leia CONTRATO.md: ele explica o resultado que o programa precisa produzir.
2. Abra um terminal nessa pasta e execute `python verificar.py` (ou `python3 verificar.py`). Inicialmente ele falha porque pipeline.py contém a tarefa ainda incompleta. Essa falha é esperada; não significa que você estragou o kit.
3. Na jornada da Academy, escolha **Com código**. Copie o pedido de cada etapa para sua ferramenta de IA. Ela ajuda a implementar pipeline.py; você confere os arquivos alterados.
4. Rode novamente o verificador. Ele é a conferência independente: não altere verificar.py ou vendas.csv para fazer a tarefa parecer correta.
5. Quando aparecer PASSOU, registre o comando e o resultado em ENTREGA.md. Repita em uma pasta nova e documente o que foi conferido e o que ficou de fora.

O uso da ferramenta de IA segue a conta e os limites do fornecedor escolhido. A jornada não inicia chamadas de IA por você.
