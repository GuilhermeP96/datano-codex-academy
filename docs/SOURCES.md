# Fontes e revisão editorial

Revisão: **02/10/2026**. Documentação oficial consultada nesta data. A CLI local `0.159.0-alpha.12.1` foi usada para conferir `codex --help`, `codex exec --help` e `codex review --help`. Por ser uma versão alpha, recursos devem ser conferidos na versão do aluno; não há promessa de paridade entre CLI, app e IDE.

As aulas, prompts, exemplos de tarefas, exercícios e quizzes foram redigidos para a DatanO Academy. As fontes abaixo sustentam comportamentos de produto e comandos, não são transcrições das aulas.
