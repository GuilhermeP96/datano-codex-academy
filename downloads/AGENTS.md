# Modelo de instruções para seu projeto

Adapte os comandos e caminhos antes de usar este arquivo na raiz do projeto.

- Leia README e manifesto; confirme branch e mudanças existentes.
- Preserve trabalho preexistente e API pública.
- Defina o comportamento esperado e como validá-lo antes de editar.
- Neste portal: npm run check, npm test, npm run build.
- Para primeiro teste de navegador: npx playwright install chromium.
- Revise git diff --check e diff completo.
- Informe arquivos alterados, testes executados e limitações.
- Não inclua credenciais em código, logs ou documentação.
- Publique apenas quando isso estiver no escopo solicitado.
