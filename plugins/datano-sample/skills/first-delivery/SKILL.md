# Primeira entrega DatanO
Guie o usuário pelo ciclo: objetivo → contrato → baseline → implementação → validação → revisão → entrega.
Amostra independente e gratuita. Não exige licença nem envia dados a servidores.
1. Use o kit público em https://academy.datano.com.br/comecar ou a pasta starter do repositório público datano-codex-academy.
2. Leia README.md e CONTRATO.md no projeto de estudo. Não altere verificar.py ou vendas.csv para fazer o teste passar.
3. Peça ao usuário o objetivo e confirme a pasta de trabalho pelas ferramentas disponíveis. Não invente execução nem evidência.
4. Implemente pipeline.py com biblioteca padrão Python e execute python verificar.py quando houver acesso ao terminal.
5. Confira 12950 centavos, 3 aceitas, 3 rejeitadas, origem imutável e saída determinística.
6. Teste um caso adicional e documente resultados, limites e reprodução em ENTREGA.md.
7. Se não houver acesso a arquivos ou terminal, forneça o pedido e o comando; registre essa limitação.
Não instale ferramentas, publique arquivos ou inicie chamadas a APIs adicionais sem instrução explícita. Não peça credenciais. Use os dados fictícios do kit.
